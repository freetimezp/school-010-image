01 THE BIG PICTURE

One image. Many possibilities.

The same photograph can look completely different depending on its container, dimensions and fitting rules.

WHY DOES IT MATTER?

Think about an online store, a portfolio or a photo gallery. Images need to fit different spaces without looking stretched, distorted or unexpectedly cropped.

HTML gives us the image element. CSS gives us control over how that image behaves.

02 HTML FUNDAMENTALS

Meet the img element.

The HTML img element embeds an image into your page. It uses attributes to define its source and alternative text.

NATURAL LIGHT / STUDY 001
THE BASIC SYNTAX

Start with an image source.

The src attribute tells the browser where to find the image. The alt attribute provides alternative text describing its content or purpose. 

<img
    src="flower.jpg"
    alt="Pink flowers"
/>
src
Image source

The path or URL of the image.

alt
Alternative text

Describes the image when needed.

i

Remember: img is a void element. It does not need a closing tag. Always consider what useful alternative text a non-decorative image should have.

03 RESPONSIVE IMAGES

Let images breathe.

A responsive image should adapt to its available space without losing its original proportions.

A SIMPLE CSS RULE

Keep images inside their containers.

An image can be wider than the screen or its parent. max-width: 100% prevents it from overflowing. 

img {
    max-width: 100%;
    height: auto;
    display: block;
}
  • Image cannot exceed its parent's width.
  • Original proportions are preserved.
  • Works naturally across screen sizes.

05 IMAGE DIMENSIONS

Shape the frame.

Aspect ratio describes the proportional relationship between an element's width and height.

WHAT IS ASPECT RATIO?

A 16:9 frame is wider than it is tall. A 1:1 frame is a square. A 3:4 frame is taller than it is wide.

WIDTH ÷ HEIGHT
SELECT A FORMAT
SELECTED FORMAT 1:1
CSS PROPERTY aspect-ratio: 1 / 1;
i

Important: aspect-ratio defines a preferred width-to-height ratio. It does not automatically crop an image. Combine it with object-fit when you need the image to fill a frame.
